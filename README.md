# melperjs

[![npm version](https://img.shields.io/npm/v/melperjs.svg)](https://www.npmjs.com/package/melperjs)

A compact JavaScript utility library for strings, objects, tokens, hashing, cookies, proxies, file I/O, shell, and more.

## Installation

```bash
npm i melperjs
```
